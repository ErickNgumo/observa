# Objective
Perform a read-only engineering and financial audit of the current Observa repository before any MVP implementation work begins.

# Why it matters
The existing project knowledge base records an evolving architecture, known correctness issues, and several historical decisions. We need a verified baseline against the actual repository so subsequent tickets are based on current code rather than stale documentation.

# Scope
- Inspect the current repository structure and build configuration.
- Compare implementation against docs/CURRENT_STATE.md, docs/ARCHITECTURE.md, docs/MVP.md, docs/DOMAIN_MODEL.md, and relevant domain documents.
- Verify the current Rust crate graph and major runtime path.
- Identify implemented, partial, broken, and undocumented functionality.
- Audit financial correctness areas: execution, spread, slippage, commission, position sizing, InstrumentSpec, PnL, equity, and metrics.
- Run existing tests and appropriate read-only checks.
- Record discrepancies with file paths and evidence.
- Propose follow-up tickets; do not implement fixes.

# Non-goals
- No production code changes.
- No dependency upgrades.
- No architecture redesign.
- No MVP scope changes.
- No packaging/release work.

# Acceptance criteria
1. Repository can be built/tested using the project's existing documented commands, or all blockers are recorded.
2. A baseline audit report identifies the actual current state of every major MVP component.
3. Every claimed discrepancy cites the repository file and relevant documentation section.
4. Financial correctness findings are independently explained and prioritized.
5. A proposed follow-up ticket list is produced, with each ticket classified as small/medium/large and financial/release where applicable.
6. No repository files are modified by the audit agent.

# Verification plan
- Architecture agent performs the audit using read-only tools.
- Finance verification is required for all monetary/calculation findings.
- Leadership reviews the final report and creates implementation tickets from it.
