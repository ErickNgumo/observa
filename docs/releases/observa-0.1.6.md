# Observa 0.1.6

This release improves the replay workspace and makes backtest inspection
clearer and easier to use.

## Replay workspace redesign

- Resizable and collapsible inspector panel
- Scrollable Trade Log with sticky headers
- Clearer account, signal, position, order and event inspection
- Compact research-focused metrics layout
- Dynamic instrument and timeframe display
- Improved Equity Curve layout
- Replay auto-follow that keeps new candles in view
- Manual pan and zoom pause auto-follow
- Separate Resume follow and Fit all controls
- Trade selection can focus the corresponding chart period
- Better desktop and laptop responsive behavior
- Improved tooltips and information hierarchy

Execution and backtest economics are unchanged.
