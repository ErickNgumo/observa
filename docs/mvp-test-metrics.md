## Qualitative questions (ask open, record verbatim key phrases)

1. What did you think Observa was for before using it?
2. What did the replay help you understand? (What did it *change*?)
3. What was confusing?
4. What part felt unnecessary?
5. What did you expect that wasn't there?
6. Would you use this on one of your real strategies?
7. What tool would you otherwise use?
8. What would stop you from using Observa again?
9. What is the first feature you would want added?

## Trust validation

> Do you trust this result more, less, or the same as a normal backtest? Why?

Watch for spontaneous mention of: visible fills, chronology, SL/TP behavior,
pending order states, exact position pairing, account state.

## Observation notes (what the tester did, not what we told them)

Use for: where they stopped, what they searched for, what they expected to
happen, where founder help became necessary (and what question they asked).
