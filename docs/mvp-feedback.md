## Categories

`EXECUTION_MODEL` `RESULTS` `REPLAY` `VISUALIZATION` `PERFORMANCE`
`ERROR_MESSAGE` `MISSING_FEATURE` `BUG` `TRUST` `OTHER`

## Severity

* **P0** — cannot use the product (wheel won't install, replay won't launch,
  valid input crashes).
* **P1** — major workflow blocker (cannot understand how to close a position,
  cannot load ordinary data).
* **P2** — significant friction (unclear error, confusing replay state).
* **P3** — improvement (layout, convenience).
* **REQUEST** — feature request with no current failure.
