# Definition of Done

A task is DONE only when all applicable conditions are true:

- The approved acceptance criteria are satisfied.
- Implementation is limited to approved scope.
- Relevant tests exist and pass.
- Regression coverage exists for bug fixes.
- Known-answer verification exists for important financial behavior.
- Architecture constraints remain satisfied.
- Documentation is updated when behavior, contracts, architecture, or current state changes.
- No failure has been hidden, suppressed, or worked around without approval.
- QA & Integration has reported PASS where required.
- Finance has reported PASS where financial logic is affected.
- Leadership has accepted significant work.
- Release requirements are satisfied when the task is a release.
