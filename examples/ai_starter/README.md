# AI Starter — Observa strategy project

Template for implementing a user strategy with an AI coding agent.

Files:
- `AGENTS.md` — instructions the coding agent reads.
- `strategy.py` — canonical Observa strategy skeleton (run: `python strategy.py`).
- `data/` — put the user's CSV here (or use the bundled sample via
  `observa.sample_data_path()`; see note in `data/`).

The human should not need to read this file; the coding agent should.
